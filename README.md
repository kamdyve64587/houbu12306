# 12306车票候补排队系统（C语言链式队列实现）
##一、题目需求理解
模拟12306候补购票排队场景，遵循队列先进先出规则，包含4项核心功能：
1. 新增候补订单：录入乘客姓名、身份证、所需票数，自动生成订单号，加入排队队尾；
2. 发放余票：输入本次放出车票总数，从队伍最前面依次分配，车票满足乘客需求则出票、移出队列，车票不足则停止分配；
3. 查看排队队列：按排队先后顺序展示所有待出票乘客信息；
4. 退出程序：释放全部动态申请的内存，避免内存泄漏。

##二、整体解题思路
### 1. 数据结构选型
排队「先来先服务」匹配**队列FIFO**特性，使用**链式队列**，无需固定数组长度，适配不定数量候补乘客：
1. Order节点结构体：存储单个乘客信息（订单号、姓名、身份证、需票数、下一位乘客指针）；
2. Queue队列结构体：存储队头front（优先出票）、队尾rear（新增乘客插入位置）。

### 2. 底层基础队列函数
1. CreateQueue：创建空队列；
2. IsEmpty：判断队伍是否无乘客；
3. EnQueue入队：新乘客添加到队尾；
4. DeQueue出队：取出队头乘客；
5. FreeAll：循环释放所有节点+队列内存。

### 3. 业务功能逻辑
1. 新增订单：校验姓名/身份证非空、票数为正整数，合法则创建节点入队；
2. 发放车票：循环判断队头乘客所需票数，剩余车票充足则出票出队，直到车票不足或队伍清空；
3. 查看队列：从队头遍历整条链表，顺序打印乘客信息；
4. 主控菜单：循环打印功能选项，接收用户输入，分发对应功能，非法输入做容错处理。
